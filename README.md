## 🛍️ Project Description

The "Book Store" project is a web application built with the Flask framework. It allows users to manage a book library seamlessly with features like adding, editing, deleting, and searching for books through a user-friendly interface.

---

## ✨ Features

- **Add Books**: Users can add new books with details such as title, author, price, and category.
- **Edit Books**: Modify the details of any book.
- **Delete Books**: Remove books from the library.
- **Search for Books**: Search easily by title or author.
- **User-Friendly Interface**: A simple and intuitive design.

---

## 🛠️ Technologies Used

- **Flask**: Backend web framework (Python).
- **HTML**: Frontend structure and design.
- **CSS**: Styles for the user interface.
- **SQLite**: Database to store book information.
